How this works
  1. /api/sso/login redirects to the Identity service, which redirects to Entra.
  2. After sign-in the browser returns to /api/sso/callback?code=... with a short-lived one-time code.
  3. The consumer exchanges the code at POST /api/auth/token and stores the tokens in HttpOnly cookies.
  4. Each call carries the token through a cookie→bearer bridge; the SDK evaluates authorization against the Identity service.
